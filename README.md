# Граф зависимостей Alpine Linux

Практическая работа № 2, вариант 16. Этап 1 читает настройки из TOML и
выводит их в формате «ключ = значение».

Нужен Python 3.11 или новее. Сборка не требуется.

```powershell
python src/main.py config.toml
python -m unittest discover -s tests -v
```

- `package` — имя пакета APK или имя из больших латинских букв в тестовом режиме.
- `repository` — URL каталога Alpine или путь к тестовому файлу относительно TOML.
- `test_mode` — использование тестового файла.
- `ascii_tree` — дополнительный вывод ASCII-дерева на этапе визуализации.

Ошибки конфигурации выводятся в stderr. Успешный запуск возвращает код 0.
